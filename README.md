# Мечта. 9:59

Атмосферный сайт книги «Мечта. 9:59» Тимофея Бородича.

Продакшен-домен: [9-59.site](https://9-59.site)

## Основные возможности

- обратный таймер;
- анимация камина;
- звуковая атмосфера часов и звуковые события собаки;
- музыкальный трек книги;
- режим чтения фрагмента книги;
- интерактивный блок о книге;
- блок автора и контакты;
- скачивание книги в нескольких форматах;
- SEO-метаданные, Open Graph и Twitter Card;
- Schema.org JSON-LD для книги и автора;
- privacy-friendly analytics events;
- адаптивная верстка.

## Локальный запуск

```bash
python3 -m http.server 8080
```

Открыть в браузере:

```text
http://localhost:8080
```

## Структура проекта

- `index.html` — основная страница сайта;
- `styles.css` — стили сайта;
- `script.js` — логика таймера, анимаций и аудио;
- `assets/images` — изображения и мокап книги;
- `assets/audio` — атмосферные звуки и музыкальный трек;
- `assets/books` — файлы книги для скачивания;
- `assets/content` — данные для режима чтения;
- `robots.txt` — правила индексации;
- `sitemap.xml` — карта сайта;
- `CNAME` — кастомный домен GitHub Pages;
- `googlefc3c29493d7a2ee3.html` — файл верификации Google Search Console;
- `AUDIO_SOURCES.md` — заметки по источникам аудиофайлов.
