# Мечта. 9:59

Атмосферный сайт книги «Мечта. 9:59» Тимофея Бородича.

Продакшен-домен: [9-59.site](https://9-59.site)

## Основные возможности

- обратный таймер;
- анимация камина;
- звуковая атмосфера часов и звуковые события собаки;
- музыкальный трек книги;
- режим чтения фрагмента книги;
- интерактивный блок о книге;
- блок автора и контакты;
- скачивание книги в нескольких форматах;
- SEO-метаданные, Open Graph и Twitter Card;
- Schema.org JSON-LD для книги и автора;
- privacy-friendly analytics events и баннер согласия (Google Consent Mode v2);
- финал таймера на 00:00 с цитатой и перезапуском, время переживает перезагрузку вкладки;
- читалка на нативном `<dialog>`: морфинг обложки через View Transitions API, запоминание страницы и размера текста, прогресс, кнопки скачивания в конце фрагмента;
- «Поделиться цитатой»: выделенный текст превращается в карточку 1080×1350 (Web Share API / скачивание);
- Media Session API: трек книги управляется с экрана блокировки;
- PWA: манифест и service worker, фрагмент доступен офлайн;
- появление блоков через scroll-driven animations (CSS `animation-timeline`) с запасным вариантом на IntersectionObserver;
- полная поддержка `prefers-reduced-motion`, пауза анимаций hero вне экрана;
- блок анонса нового романа;
- дизайн: плёночное зерно, свет камина в блоке о книге, глубина сцены за курсором, подсказка «листать вниз», ровный таймер с мягкой сменой цифр, эквалайзер в кнопке трека, 3D-наклон книги с бликом, нумерация глав, цитата-пауза, свёрнутая правовая информация;
- читалка: ночной режим, буквица, текстура бумаги;
- адаптивная верстка.

## Локальный запуск

```bash
python3 -m http.server 8080
```

Открыть в браузере:

```text
http://localhost:8080
```

## Структура проекта

- `index.html` — основная страница сайта;
- `styles.css` — стили сайта;
- `script.js` — логика таймера, анимаций, аудио и читалки (ES-модуль);
- `sw.js` — service worker (при изменении списка файлов увеличьте `VERSION`);
- `manifest.webmanifest` — манифест PWA;
- `assets/images` — изображения и мокап книги;
- `assets/audio` — атмосферные звуки и музыкальный трек;
- `assets/books` — файлы книги для скачивания;
- `assets/content` — данные для режима чтения;
- `robots.txt` — правила индексации;
- `sitemap.xml` — карта сайта;
- `CNAME` — кастомный домен GitHub Pages;
- `googlefc3c29493d7a2ee3.html` — файл верификации Google Search Console;
- `AUDIO_SOURCES.md` — заметки по источникам аудиофайлов.
