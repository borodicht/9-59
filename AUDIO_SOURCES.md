# Audio Sources

Сетевое скачивание в текущей среде недоступно, поэтому фоновые звуки нужно добавить вручную в указанные пути.

## Добавленный автоматически файл

- `assets/audio/music/book-track.mp3`
  Источник: пользовательский локальный файл, предоставленный вручную
  Примечание: это единственный предоставленный пользователем музыкальный трек книги.

## Подключённые вручную фоновые файлы

- `assets/audio/ambient/fireplace.mp3`
  Страница: [Pixabay — Sound of a fantastic, warm fireplace](https://pixabay.com/sound-effects/household-sound-of-a-fantastic-warm-fireplace-141728/)
  Лицензия: Pixabay Content License
  Локальный источник: добавлен вручную из пользовательской среды
  Примечание: длительность 1:38, подходит под спокойный зацикливаемый камин.

- `assets/audio/ambient/clock.mp3`
  Страница: [Pixabay — Mechanical clock ticking for one minute](https://pixabay.com/sound-effects/film-special-effects-mechanical-clock-ticking-for-one-minute-364933/)
  Лицензия: Pixabay Content License
  Локальный источник: добавлен вручную из пользовательской среды
  Примечание: длительность 1:01, подходит как тихое равномерное тиканье старых часов.

- `assets/audio/ambient/dog-breathing.mp3`
  Страница: [Pixabay — Dog Panting](https://pixabay.com/sound-effects/dog-panting-8901/)
  Лицензия: Pixabay Content License
  Локальный источник: добавлен вручную из пользовательской среды
  Примечание: длительность 0:46; перед использованием стоит подрезать и сделать звук тише, чтобы он стал почти незаметным дыханием большой собаки.

- `assets/audio/ambient/dog-howl.mp3`
  Страница: [Freesound — Dog Howl by Latranz](https://freesound.org/people/Latranz/sounds/518566/)
  Лицензия: требуется проверить вручную для локального файла
  Локальный источник: добавлен вручную из пользовательской среды
  Примечание: одиночный тихий вой, не зацикливать. Для этого файла источник и лицензия в проекте пока не подтверждены.

- `assets/audio/effects/clock-tick.mp3`
  Страница: [Pixabay — Clock Ticking SFX](https://pixabay.com/sound-effects/clock-ticking-sfx-467486/)
  Лицензия: Pixabay Content License
  Локальный источник: добавлен вручную из пользовательской среды
  Примечание: взять один отчётливый тик из файла и при необходимости подрезать до короткого одиночного эффекта.
